{% comment %} ------------------------------------------- development "How is my child developing?" — RFP §6.4. Only the levels a teacher marked visible to families. That gate is in `assessment.selectors.child_assessments`, which filters `visible_to_parents=True` for a guardian; nothing here re-implements it and nothing here may widen it (CLAUDE.md §1.1). A list, not a chart. Each row is a domain, its level in words, and the level's own numeral — no percentage, no average, no comparison against other children, because none of those figures exists in the backend and inventing one would be a claim about a child that nobody made. Domain names and level labels are read from the configured `DevelopmentDomain` and `AssessmentLevel` rows (§6.1, §6.2), never hardcoded — a kindergarten that renames a level sees the new name here. The level's colour comes from the **level**, never from the domain: a domain-tinted level badge reads as a severity scale running the wrong way, which is a mistake this codebase has already made twice. {% endcomment %}
